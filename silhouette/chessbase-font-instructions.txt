To install the silhouette fonts on Chessbase products, remove the DiaTTOld.otf and DiaTTOld.ttf font from your system and reinstall the downloaded DiaTTOld.ttf from this folder. You can also remove the other font files that start with Diag from your system to allow the DiagTTOlf font to be used in other mini chessboard display within Chessbase.  
The other font files in this folder, the DiaTTShahi and Shahi-Silhouette-English-Regular and Shahi-Silhouette-Turkish-Regular are essentially the same font with different file name. Chessbase products in future will start using DiaTTShahi font which can be downloaded from this folder. The Turkish and English versions correspond to different keymap for the pieces respectively.
